## ✨ 目前已经搞定的功能
- **多格式支持**：TXT、EPUB、PDF、ZIP（漫画包）统统拿下。
- **两种阅读模式**：传统“左右翻页” + 刷图专用的“上下滚动（条漫模式）”。
- **护眼与夜间**：四种背景色随便切（纯白、羊皮纸、护眼绿、夜间黑）。
- **贴心小功能**：自动识别小说目录、长按复制文字、一键加书签、记录阅读时长。
- **防闪退优化**：针对大体积漫画包做了内存保护。

## 📲 如何下载安装
1. 点击页面右侧的 **Releases**。
2. 下载最新的 `.apk` 安装包。
3. 安装到手机即可。（注：因为是个人开发，系统可能会提示风险，点“继续安装”或“无视风险”即可，绝对绿色无毒。）
